브라우저 확장을 설치하세요

이 화면은 JiraWorklog 연결 도우미 확장을 거쳐, 이 브라우저에 로그인된 Jira 로 작업 로그를 조회·기록합니다. API 토큰은 필요 없습니다. Chrome · Edge 에서 사용할 수 있습니다.

  1. 설치 파일 받기 (zip) 설치 파일이 아직 준비되지 않았습니다. 관리자에게 문의하세요.
  2. 압축을 풀어 지우지 않을 폴더에 둡니다. 예: 문서\jira-worklog-bridge
  3. 주소창에 chrome://extensions (Edge: edge://extensions) 를 엽니다.
  4. 개발자 모드를 켜고 압축해제된 확장 프로그램을 로드합니다(Edge: 압축을 푼 항목 로드)를 눌러 그 폴더를 고릅니다.
  5. 이 화면으로 돌아와 다시 확인을 누릅니다.

브라우저 확장을 업데이트하세요

설치된 JiraWorklog 연결 도우미 확장이 오래되어 이 웹과 함께 쓸 수 없습니다.

설치됨 → 최신

  1. 새 설치 파일 받기 (zip) 설치 파일이 아직 준비되지 않았습니다. 관리자에게 문의하세요.
  2. 압축을 풀어 나온 jira-worklog-bridge 폴더의 내용으로 기존 확장 폴더를 덮어씁니다. 폴더 위치를 모르면 확장 페이지에서 확장 카드의 세부정보를 열어 확인합니다.
  3. 주소창에 chrome://extensions (Edge: edge://extensions) 를 열고, JiraWorklog 연결 도우미 카드의 새로고침(↻) 버튼을 누릅니다.
  4. 이 화면으로 돌아와 다시 확인을 누릅니다. 버전이 바뀌지 않으면 브라우저를 완전히 종료했다가 다시 엽니다.

확장을 지우고 새로 설치해도 됩니다 (설치 방법은 설치 파일 안 README.txt).

Jira 에 로그인하세요

이 브라우저에서 Jira 에 로그인되어 있지 않습니다. Jira 를 열어 회사 SSO 로 로그인한 뒤 다시 확인을 누르세요.
