개인정보처리방침

JiraWorklog 연결 도우미 (Chrome 확장) · 시행일 2026-10-27

JiraWorklog 연결 도우미(이하 “확장”)는 NC AX 회계개발팀이 사내용으로 만든 브라우저 확장입니다. 회사 내부망에서만 열리는 사내 웹 화면 Jira 투입공수 집계(이하 “웹”)가 보낸 Jira 요청을, 이 브라우저에 로그인된 Jira 세션으로 회사 Jira 사이트(nckorea.atlassian.net)에 전달하는 일만 합니다. 이 방침은 확장과 웹이 어떤 데이터를 어떻게 다루는지 설명합니다.

1. 다루는 데이터

  • Jira 계정 정보: 로그인한 사용자의 계정 ID, 이름, 이메일, 시간대
  • 작업 로그(worklog)와 일감 정보: 일감 키·제목·상태·상위 일감, worklog 의 작성자·일자·시간·설명
  • 팀원 정보: 사용자가 팀원으로 등록하거나 검색한 Jira 사용자의 계정 ID·이름·이메일, Jira 그룹 이름

모두 사용자가 이미 Jira 에서 볼 수 있는 데이터이며, 사용자 본인의 Jira 권한으로만 읽고 씁니다.

2. 확장이 하는 일과 하지 않는 일

  • 요청은 회사 Jira 사이트 한 곳에만 보냅니다. 경로는 투입공수 집계에 필요한 것만 허용하며, 쓰기는 사용자가 화면에서 직접 누른 worklog 추가·수정·삭제뿐입니다.
  • 요청은 확장에 등록된 사내 웹 주소에서 온 것만 받고, 응답은 그 웹 화면에만 돌려줍니다.
  • 확장은 데이터를 저장하지 않습니다. 쿠키·비밀번호·토큰을 읽거나 따로 보관하지 않으며, 로그인은 브라우저가 Jira 쿠키를 그대로 붙여 처리합니다.
  • 방문 기록, 다른 웹 페이지의 내용, 입력·클릭 같은 사용자 활동을 수집하지 않습니다.
  • 광고·분석·추적 도구를 쓰지 않습니다.

3. 사내 웹 서버에서의 처리와 보관

  • 조회·집계 결과는 사용자의 브라우저 탭 세션 동안 서버 메모리에만 잠시 둡니다. 데이터베이스나 디스크에 쓰지 않으며, 사용하지 않는 세션은 12시간 뒤 지워지고 서버를 다시 시작해도 사라집니다.
  • 서버 운영 로그에는 연결한 계정 ID, worklog 를 추가·수정·삭제한 일감 키, 통계 조회의 건수·소요 시간만 남깁니다. worklog 설명·일감 제목 같은 내용은 남기지 않습니다.
  • 서버에는 Jira 토큰이나 비밀번호가 없습니다.

4. 사용자 브라우저에 저장되는 데이터

  • 화면 설정(팀원·그룹·보기 옵션·테마)은 이 브라우저의 localStorage 에 Jira 계정별로 저장합니다.
  • 통계 화면의 동기화 데이터(최근 366일의 본인·팀원 worklog)는 이 브라우저의 IndexedDB 에 저장합니다. 통계 화면의 [보관 데이터 지우기] 또는 브라우저의 사이트 데이터 삭제로 언제든 지울 수 있습니다.

5. 제3자 제공

사용자 데이터를 판매하거나 제3자에게 제공·전송하지 않습니다. 데이터는 사용자의 브라우저, 회사 Jira 사이트, 사내 웹 서버 사이에서만 오가며, 투입공수 조회·기록 외의 목적으로 쓰지 않습니다.

6. 삭제

확장을 제거하면 확장이 더 이상 요청을 전달하지 않습니다. 브라우저에 남은 화면 설정과 동기화 데이터는 4항의 방법으로 지울 수 있습니다. Jira 에 기록한 worklog 는 Jira 의 데이터이므로 Jira 에서 관리합니다.

7. 변경과 문의

이 방침이 바뀌면 이 페이지의 내용과 시행일을 고칩니다. 문의는 NC AX 회계개발팀으로 해 주세요.
